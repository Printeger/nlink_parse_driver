# UWB ROS2 driver

This repository now targets Ubuntu 24.04 / ROS 2 Jazzy. See the [current Chinese operating guide](README.md), [migration boundaries](docs/ros2_migration.md), and [software acceptance report](docs/software_acceptance.md).
